## 📌 Overview
A fully responsive multi-page web application built with React, Tailwind CSS and Strapi CMS.
The project includes a homepage, a models showcase with interactive overlays, a culture page with
custom swipers and animations, multiple dropdown navigation pages, and a fully responsive navigation
menu with a burger menu for mobile — each fully optimized across all device breakpoints.

---

## 🎯 Project Goal
This project was developed as part of my learning journey at **Step IT Academy**.
The goal is to build a modern, high-quality web application simulating a luxury automotive
brand platform, focusing on responsive design, component architecture, and CMS integration.

## ✨ Features

- Fully responsive across **mobile, tablet and desktop**
- Breakpoint-specific components for precise layout control
- Custom **keyframe animations** and transitions
- Responsive **burger menu** for mobile with smooth open/close animation
- Breakpoint-driven **navbar behavior** switching between mobile, tablet and desktop layouts
- **Swiper.js** carousels with custom navigation and progress bars
- Dynamic content powered by **Strapi CMS** via REST API
- Interactive **Leaflet world map** with custom zoom controls
- Slug-based data matching across Strapi collections
- Staggered hover animations on model overlays
